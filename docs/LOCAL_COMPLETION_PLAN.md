# 本地补齐批次

当前版本b12710b单次导出超过50,000条或10MiB拒绝，而且先加载全部历史；导入每块重新加载所有本机记录。因此大量历史没有安全可用的大文件路径，本批需要修改。

沿用每块原有version1 usage schema，不新增同步后端：单文件JSONL容器由header、多个独立version1块、complete footer组成，footer记录确切块数/记录数，缺失或不符不能称完成。导出在独立SQLite只读快照中遍历，以临时散列身份索引去重，本机记录优先，不加载全部历史到JS内存。新增有界本地导出任务用于网页进度/取消；原JSON文件API保留兼容。

导入浏览器流式读取有界JSONL行，每块独立校验/事务/去重；取消在当前块确认后停。后续块失败、缺失footer或网络状态不确定必须显示已确认前缀与不完整结果，允许重导去重；不得把部分导入称全部成功。旧JSON文件仍接受原version1与10MiB上限。只读评估本机官方协议schema/现有daemon，不读取sessions路径、不运行模型、不自动启动daemon、不绕过认证。

验收：超过旧限制的大样本，多块重导和本机优先，非法字段/凭据继续拒绝；footer截断/数目不符、取消与失败结果；Windows页面真实下载/导入/进度，原Dashboard/HUD回归，完整build/tests，单独commit/push后停止。
